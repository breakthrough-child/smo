Show Me Once

A helper shows a phone task once; AI turns it into a spotlight tour their parent follows alone, read aloud.

Scope → PRD

Scope said “the parent follows the tour alone.” Now we know exactly what that means: tapping the glowing circle advances, tapping elsewhere coaches “Tap the glowing circle,” each step is read aloud at 0.9 speed, and if voice isn't available the tour continues text-only.

The core journey

  1. Landing → Make a guide
  2. Create: task name + video (3–90 s) or 2–15 screenshots; privacy notice
  3. Building: friendly stages; “Please keep this page open.”
  4. Review: move circle, edit text, delete step, publish (re-openable to edit live)
  5. Share: editable message → Send on WhatsApp / Copy link
  6. Start (parent): huge button, unlocks voice
  7. Steps: spotlight, voice, tap the circle or Got it, next → You did it!

Screen by screen

Landing + Create

/

Behavior

  • “Show it once. They've got it forever.” + 3-step explainer + Make a guide
  • Task name (required); one video or 2–15 screenshots with order preview
  • Notice: don't record passwords, PINs or balances
  • Building stages: Reading your video… → Finding the taps… → Writing the steps… + “Please keep this page open.”

What if

  • Video won't open → message + switch to screenshots
  • Under 3 s → “That recording is too short — try recording the whole task.”
  • Over 90 s → “Shorter is clearer! Record just this one task, under 90 seconds.” Both: Choose another video + screenshots
  • <2 or >15 screenshots → inline message, button disabled
  • AI failure → “Something went wrong…” + Try again (upload kept)
  • No steps → “I couldn't spot any taps in this one.” + Try again + tips

Done when

  • iPhone recording → guide → Review
  • Android recording → guide → Review
  • 2–15 screenshots → guide → Review
  • Stages visibly change while waiting

Review

/g/[id]/review (needs edit key)

Behavior

  • Step cards: number, screenshot + circle, editable instruction
  • Drag circle (stays inside the screenshot); delete step with confirm
  • Confidence < 0.6 → “Please check this step”
  • Sensitive flag → banner at top
  • Publish → Share; once published it's Save changes and edits go live
  • Delete this guide → confirm → “Guide deleted”

What if

  • All steps deleted → Publish disabled, “Keep at least one step.”
  • Empty instruction → can't publish that step
  • No/wrong edit key → “This link can't edit this guide.”

Done when

  • Move / edit / delete all show in the tour after publishing
  • Editing a published guide changes the live tour
  • Deleted guide's link shows the missing-guide page

Share

Behavior

  • Editable message, prefilled: “Hi! I made you a simple step-by-step guide for [task]. Just tap the link and follow along at your own pace. 💛 [link]”
  • Send on WhatsApp sends whatever's in the box

  • Helper removes the link → added back on a new line at the end

Done when

  • On a phone, Send on WhatsApp opens WhatsApp with the edited message and a working link
